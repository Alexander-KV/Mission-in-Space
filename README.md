Mission in Space

Игра по мотивам "Звёздных войн". Игроку предстоит высадиться на звёздный разрушитель, скачать чертежи с терминала в лаборатории и уничтожить реактор корабля. На пути будут встречаться враги и другие трудности.

Сюжет и цель:

Вы — боец сопротивления. Имперский флагман угрожает всему сектору. Ваша миссия:

-Высадиться в грузовом отсеке разрушителя.

-Найти лабораторию и скачать чертежи с терминала.

-Пробиться к реакторному отсеку и уничтожить реактор.

-Эвакуироваться до взрыва.

Особенности:

-Атмосфера в стиле классической трилогии.

-Враги: штурмовики, турели, летающие дроиды.

Управление (по умолчанию):

-Движение: WASD
-Прицел и стрельба: мышь (ЛКМ)
-Смена оружия: 1, 2, 3
-Использовать (терминал, двери): E
-Пауза: ESC

Как запустить:

Минимальные требования:
Наличие ПК с:
-Windows 10/11 (или Linux через Proton)

-2 GB RAM

-Видеокарта с OpenGL 3.3

-Запуск:

-Скачать последнюю версию из папки Releases (или со страницы сборок).

-Распаковать архив в любую папку.

-Запустить MissionInSpace.exe.

-Сборка из исходников:

-Клонировать репозиторий.

-Открыть проект в Unity (или вашем движке).

-Собрать под свою платформу.

Используемые технологии:

-Движок: Unity 2022.3 LTS
-Язык: C#
-Модели: Blender + бесплатные ассеты
-Звуки: собственная обработка
